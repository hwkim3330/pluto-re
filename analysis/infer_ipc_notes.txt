  built for %lu/%lu); using pipes", UnmapViewOfFile.
V On match: writes u32 +0x10 = 'PLSM' (ack) BEFORE sending handshake; logs "transport: shared memory + events" after handshake.

WAIT LOOP (0x140151f3e..)
V loop: if quit(+0x14) -> exit; if +0x40 != last -> serve; else WaitForMultipleObjects(2, {req_ev, parent_handle},
  FALSE, INFINITE). ret 0 -> re-check; ret 1 -> "parent process exited"; other -> "shm wait failed";
  both then "[pluto_infer] shutdown after %ld steps; exiting", exit 0.
V serve: last = +0x40; copy 0x30 header from +0xc0; memcpy payload arrays from shm (no bounds beyond N check);
  run step FUN_140034f10(out, model, inputs, forced_or_NULL); write response to +0x85f40 (10 dwords), +0x80 = last,
  SetEvent(resp_ev). Then FUN_14002b8d0(model) = next-step prelude work (I: latency hiding, "prelude" in bench).
V --verbose: "[pluto_infer] step %ld N=%d a=%d arg=%d pos=%lld u=%d lp=%.3f win=%.3f".

PIPE TRANSPORT (BWRL_SHM=0 or attach failure)
V stdin/stdout set to _O_BINARY. Request = fread 0x30 header (short read/EOF -> "shutdown after %ld steps", exit 0),
  then same arrays contiguous, no padding: N*0x30, N*0x1b4, N, N, 20, 233, 292*4, 0x8000, 0x4000, 0x20.
  Any short read -> "truncated request payload", exit 1. Response = 0x28 bytes on stdout + fflush; failure ->
  "response write failed", exit 1.

EXIT CODES: 0 clean shutdown (quit flag / parent exit / wait fail / stdin EOF); 1 fatal (no AVX2, init failure,
 max_units cap, handshake write, bad header, truncated payload, response write); 2 usage (unknown arg/backend, --log fail).
Logging: everything to stderr (= pluto_infer.log from DLL); stderr set unbuffered (setvbuf mode 4).
